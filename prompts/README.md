# Prompts

A prompt is one tested question. Paste it into any agent, or ask Inch to run it by name.

Every prompt says what it needs, what you still check yourself, and what happened when it was tested.

| Prompt | Needs | Tested |
|---|---|---|
| [Why didn't this host stop?](why-didnt-this-host-stop.md) | A task log export (CSV) | 16 Oct 2026 |
| [Which hosts are still running, and why?](which-hosts-are-still-running.md) | [Nerdio Manager MCP server](../connections/nerdio-mcp.md) | 16 Oct 2026 |
| [Which counter is my Log Analytics bill?](which-counter-is-my-log-analytics-bill.md) | [Azure MCP Server](../connections/azure-mcp.md) | 15 Oct 2026 |

## Add a prompt

Copy the shape of an existing one: **Use it when**, **Prompt**, **Needs**, **You still check**, **Tested**. Test it against a real environment before you add it. Then add a row here and in [../AGENTS.md](../AGENTS.md).
